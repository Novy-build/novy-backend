# Historical Frontend Handoff

These files are preserved copies of the frontend handoff that was present in the backend workspace
before the backend documentation was established. They are historical context, not backend policy,
backend implementation, or evidence that a backend test passed. Some paths and status claims are
outdated. The current frontend repository owns its own documentation and integration contracts.

Use the backend root `AGENTS.md`, `PROGRESS.md`, and `BACKEND_PLAN.md` for current backend rules,
status, and plans. When reconciling product and wire contracts, consult the canonical product PDF
and the actual frontend DTOs, mappers, repositories, and tests referenced there.
